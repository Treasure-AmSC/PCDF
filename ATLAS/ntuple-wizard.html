What the program does

  • Reads the fields you choose from CollectionTreeThe ROOT tree that stores events and physics objects in an ATLAS DAOD..
  • Writes one Parquet table for each object you select.
  • Uses the task and file numbers from a standard ATLAS filename. For other names, it uses the ROOT file IDA 128-bit UUID stored inside a ROOT file. It stays the same if the file is renamed..
  • Keeps the generated table links unique within each task or file.
  • For collision data, skips truth and flavor fields and adds lumiBlock to Events.

Select output objects

Each object you select becomes a Parquet table. The program gets file IDs from the ATLAS filename when it can. Otherwise, it reads the ID stored in the ROOT file. Turning off an object also turns off tables that need it.

Help and glossary

Using the wizard

  1. Choose the DAOD format and whether the sample contains simulation or collision data.
  2. Choose the physics objects and variables you need.
  3. Review the Perlmutter settings if you want a SLURM job script.
  4. Download the bundle. Its README explains how to run it.

The generated Python program writes one Parquet table for each selected object. Standard ATLAS filenames provide the task and file numbers. For other filenames, the program uses the ID stored in the ROOT file.

Terms

ATLAS DAOD
An ATLAS analysis data format stored in a ROOT file.
JETM16
An ATLAS DAOD made for jet studies. It includes detailed jet content.
PHYSLITE
A compact ATLAS DAOD with objects used in many analyses.
Object
A group of related event data, such as jets or electrons. Each selected object becomes a Parquet table.
Variable
One value stored for an object. It becomes a column in the Parquet table.
Parquet
A column-based data format that works well with tools such as Pandas.
CollectionTree
The ROOT tree that stores events and physics objects in an ATLAS DAOD.
ROOT file ID
A 128-bit UUID stored inside a ROOT file. It stays the same if the file is renamed.
SLURM
The system that places jobs in a queue and runs them on Perlmutter.
NERSC Perlmutter
The NERSC supercomputer where this job script runs.
Input manifest
A text file with one input file path on each line.
