    Help and glossary

    Terms

    ATLAS DAOD
    An ATLAS analysis data format stored in a ROOT file.
    JETM16
    An ATLAS DAOD made for jet studies. It includes detailed jet content.
    PHYSLITE
    A compact ATLAS DAOD with objects used in many analyses.
    Object
    A group of related event data, such as jets or electrons. Each selected object becomes a Parquet table.
    Variable
    One value stored for an object. It becomes a column in the Parquet table.
    Parquet
    A column-based data format that works well with tools such as Pandas.
    CollectionTree
    The ROOT tree that stores events and physics objects in an ATLAS DAOD.
    ROOT file ID
    A 128-bit UUID stored inside a ROOT file. It stays the same if the file is renamed.
    SLURM
    The system that places jobs in a queue and runs them on Perlmutter.
    HTCondor
    A workload manager that queues independent jobs. This wizard expects a filesystem shared by its access point and execute nodes.
    NERSC Perlmutter
    The NERSC supercomputer where this job script runs.
    Input manifest
    A text file with one input file path on each line.
