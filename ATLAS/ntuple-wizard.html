ATLAS TREASURE → Parquet script wizard

Interactively select DAOD objects and variables, then download a custom Python script that writes each selected object to its own Parquet folder.

Choose the DAOD input

TREASURE includes PHYSLITE-like analysis objects plus additional content from the TREASURE derivation. PHYSLITE can be used directly, but jet constituent Particle Flow containers are not available there.

Generated script behavior

  • Uses uproot, awkward, numba, pyarrow, rich, and click, matching ATLAS/ntuple-maker.py.
  • Reads the selected branches from CollectionTree.
  • Writes Event/data.parquet, Jet/data.parquet, and other selected object folders under the requested output directory.
  • Adds object-local indices plus eventIndex links; jet constituents and ghost tracks also include jetIndex.

Select output objects

Each checked object becomes a subdirectory with a data.parquet file. Deselecting an object also deselects any objects that depend on it.

Choose variables

Variables are grouped by object. Four-vector components are required and cannot be deselected.

Search research PHYSLITE datasets, pick a match, and preview file count, bytes, and transfer time.

Local run: uv run ntuple-maker.py input.pool.root -o parquet-output.

  1. Preview the Open Data dataset so you know how many files and approximate bytes will be copied.
  2. Download the tar bundle, copy it to Perlmutter, and extract it with tar -xf pcdf-ntuple-bundle.tar.
  3. Log in to a Perlmutter data transfer node and run ./download-atlas-opendata.sh; it downloads to scratch and writes the manifest.
  4. Return to a login node, ensure uv and GNU parallel are available, then submit with sbatch submit-pcdf-ntuple.slurm.
  5. Monitor with squeue -u $USER; inspect pcdf-ntuple-<jobid>.out, .err, and per-node GNU parallel logs in the output base directory.
